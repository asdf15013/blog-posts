Windows 的亚克力、macOS 的毛玻璃、iOS 的大标题模糊——**玻璃拟态（Glassmorphism）** 一直是界面设计里最讨喜的风格之一。这个小站就是一次实践。

## 核心：backdrop-filter

一句话解释：让元素**背后的内容**参与模糊。

```css
.glass-card {
  background: rgba(255, 255, 255, 0.55);
  border: 1px solid rgba(255, 255, 255, 0.85);
  border-radius: 20px;
  backdrop-filter: blur(20px) saturate(160%);
}
```

三个关键参数：

| 属性 | 作用 | 建议值 |
| --- | --- | --- |
| `background` | 半透明底色，决定"玻璃感" | 透明度 0.4 ~ 0.7 |
| `backdrop-filter` | 背后内容的模糊与饱和度 | blur 12~24px |
| `border` | 边缘高光，模拟玻璃厚度 | 半透明白色 1px |

## 玻璃下面必须有东西

玻璃拟态成立的前提是**背景要有层次**：渐变色、光斑、彩色形状。一块纯色背景上的毛玻璃，看起来只是块半透明的板子。

本站的做法：渐变底色 + 三个缓慢漂浮的模糊光斑（`filter: blur(90px)` 的大圆），让玻璃卡片背后永远有流动的色彩。

## 三个常见的坑

1. **性能**：`backdrop-filter` 开销不小，页面别铺满大块玻璃，滚动区域的玻璃要克制
2. **可读性**：文字底下的玻璃要保证足够对比度，暗色主题下尤其注意
3. **兼容性**：Safari 需要加 `-webkit-backdrop-filter` 前缀

## 明暗主题各美其美

- 亮色：奶白玻璃 + 紫蓝渐变，清透干净
- 暗色：深色玻璃 + 低透明度光斑，晶莹剔透

> 玻璃拟态的本质，是用透明与模糊制造「层次」与「深度」。

克制地用，它就是界面里最优雅的那层纱。
